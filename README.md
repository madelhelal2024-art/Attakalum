# السلسلة الصوتية التفاعلية — Interactive Arabic Phonics Book

نموذج الويب التفاعلي للصفحتين **٢٠ و٢١** من الوحدة الأولى، **صوت حرف الألف**.

## المميزات
- صور صفحات الكتاب الأصلية دون إعادة تصميم.
- عرض صفحة واحدة وصفحتين، مع تنقل وتكبير للصفحة.
- تكبير **كل نشاط على حدة** بالأصول الأصلية.
- تشغيل أربعة تسجيلات صوتية أصلية.
- نشاط أستمع وأضع دائرة مع الإجابات والتصحيح.
- نشاط أتبع وأكتب باستخدام القلم/الفأرة فوق الصفحة.
- الواجهة باللغة العربية ومتجاوبة مع الكمبيوتر والهاتف.

## بنية المشروع

```
index.html
assets/
  page20.png
  page21.png
  act_a.png
  act_b.png
  act_c.png
  act_d.png
  act_h.png
  01-01-01-18A.mp3
  01-01-01-18B.mp3
  01-01-01-19D.MP3
  01-01-01-19H.MP3
```

**مهم:** لن يعرض التطبيق الصفحات أو يشغّل التسجيلات إلا بعد رفع الملفات الأصلية أعلاه إلى مجلد `assets` بأسمائها الصحيحة. لا تُنشئ صورًا بديلة.

## النشر عبر GitHub Pages

افتح **Settings → Pages → Build and deployment → Deploy from a branch** وحدد `main` و `/(root)` ثم احفظ.

الرابط المتوقع **بعد تفعيل Pages ورفع جميع الملفات**:
https://madelhelal2024-art.github.io/Attakalum/

## الاستخدام

افتح `index.html` محليًا باستخدام خادم HTTP أو افتحه من GitHub Pages. اختر وضع عرض الصفحات، واضغط على أي نشاط لفتحه مكبرًا، ثم تفاعل مع الصوت والتدريبات.

> الصور والصوتيات مرفقة من صاحب المشروع؛ الرجاء مراجعة تراخيص استخدامها قبل نشر المستودع للعامة.
